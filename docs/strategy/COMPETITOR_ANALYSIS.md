# 競合分析およびサイト戦略策定 (Competitive Analysis & Strategy)

このドキュメントでは、DMM AV アフィリエイト領域における成功モデルを分析し、本プロジェクトが目指すべきサイトの方向性、ターゲットオーディエンス、および SNS での成長戦略を定義します。

## 1. 目的
- 伸びている既存アフィリエイトアカウント（Twitter/X）の成功要因を解明し、当サイトの自動化エンジンに応用する。
- ユーザーに真に価値のある「セール＆最安値情報」を提供し、高いCVRを実現する。

## 3. サイトの方向性とターゲット
- **ターゲットオーディエンス**: 
    - DMM の特定のフロアやジャンルを定期的にチェックしているライト〜ミドル層。
    - 「安く買いたい」「今の価格が本当に最安値か知りたい」という購買意欲の高い層。
- **サイトの方向性**:
    - 「雑多なリンク集」ではなく、**「価格変動を可視化するデータドリブンなセール通知ポータル」**。
    - システムが勝手に収集・投稿するため、管理コストを最小限に抑えつつ、常に鮮度のある情報を提供し続ける。
